# Examples

Small, runnable recipes for the most common ways people use CliMA, each
spanning several packages. Every example is its own Julia environment in
the root workspace, so it runs against this checkout. It ends with a
`@testset`, and CI runs it whenever any package it uses changes, so the
examples can't quietly go stale.

```bash
julia --project=examples/<name> examples/<name>/run.jl
```

| Example | What it shows | Packages | CI |
|:--|:--|:--|:--|
| [Add your own closure to ClimaAtmos and calibrate it](atmos-custom-closure-calibration/) | Add a K-profile closure to ClimaAtmos and recover its parameters on GABLS with EKI | ClimaAnalysis, ClimaAtmos, ClimaCalibrate, ClimaCore | every PR |
| [ClimaAtmos single-column simulation](atmos-single-column/) | Run 10 minutes of the BOMEX single-column case and read diagnostics with ClimaAnalysis | ClimaAnalysis, ClimaAtmos | every PR |
| [Build your own model on ClimaCore](build-on-climacore/) | 1D column heat diffusion with ClimaCore operators, integrated by ClimaTimeSteppers | ClimaComms, ClimaCore, ClimaTimeSteppers | every PR |
| [Calibrate a toy model](calibrate-toy-model/) | Recover two parameters of a logistic-growth model with ClimaCalibrate and EKI | ClimaCalibrate | every PR |
| [Coupled slabplanet (atmosphere + land + slab ocean)](coupled-slabplanet/) | Run 5 coupling steps of a coarse global ClimaCoupler slabplanet and check its budgets | ClimaAtmos, ClimaComms, ClimaCore, ClimaCoupler, ClimaLand | nightly |
| [Single-column soil simulation](land-single-site/) | Run a 2-day ClimaLand soil column (water + heat) and check its budgets close | ClimaLand | every PR |
| [CliMA physics in your own model](physics-in-your-model/) | Thermodynamics, 1-moment microphysics and surface fluxes on plain scalars and arrays | ClimaParams, CloudMicrophysics, SurfaceFluxes, Thermodynamics | every PR |

"nightly" examples are too heavy for every PR and run on the nightly
schedule. The list above is generated by `julia tools/mono.jl examples --list`
from each example's `example.toml`.

## Adding an example

1. Create `examples/<name>/` with `Project.toml`, `run.jl` (ending in a
   `@testset`), `README.md`, and `example.toml` (`title`, `summary`,
   `nightly`, `timeout_minutes`).
2. Run `julia tools/mono.jl workspace` and `julia tools/mono.jl codeowners`.
3. Keep it short and CPU-only. Use only documented API; if you need a
   workaround for a package bug, mark it `WORKAROUND` and open an issue.

For long GPU simulations, see [../experiments/](../experiments/).
